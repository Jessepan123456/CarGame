# Car Game
A Car game built with Godot Engine where players control a car through tracks or endless roads. The project focuses on learning game physics, scene management, gameplay system, and visuals. 

## Features
- Player-controlled car movement with acceleration mechanics
- Lap/Countdown system
- Collision detection
- Endless and Level system
- GPU particles effects 
- Simple racing UI
- Sound effects and background music
- Visual for cars and levels, allowing switching skins
- Implemented lighting
- A simple AI Enemy

## How to Run
1. Clone or download the repository
2. Open the project in Godot
3. Run the main scene/project by pressing F5 or the start button
4. Use keyboard wsad to drive, shift for boost, space for light

Example:
W / Up Arrow -> Up
S / Down Arrow -> down
A/D or Left/Right Arrow -> Turn

## What I Learned

- Working with nodes, scenes, and signals
- Creating movement for users
- Implementing a collision and lap system
- Using GPU particles for visual effects
- Managing game state and Player State Machine
- Organizing folders with reusable scripts and scenes.
